# Progress report — v6.34 (2026-11-15)

## What shipped
- **A ladder.** Ranked play now has standings. Open **The ladder** from the first screen, **See the ladder** from the server table screen or the name sheet, and you read the best ranked players by rating:
  their rank, name, rating and record. Anyone can read it; looking does not sign you in.
- **How you get on it.** Choose a player name and play three ranked games. Until then you are rated but "provisional": the screen says so ("2 more ranked games and you are on the ladder") and shows your
  row highlighted once you are in. The list shows the top fifty; if you are listed below that you still hear your own rank.
- **Latest games.** Under the ladder, the last ten ranked results: who beat whom, with which heroes, how it ended (won, conceded, forfeit, draw) and how long ago.
- **Plain and honest.** An empty ladder says "No one is on the ladder yet. Be the first: play three ranked games."; a failure says the ladder is not answering and offers *Try again*. The screen says what it is:
  a fan-made ladder, for fun and glory, no ads, forever. Long names and four-digit ratings fit on a small phone.

## Not known / not built yet (the honest list)
- **Not deployed.** One new SQL file (`008_ladder.sql`, run it first) and a new function version. The live check's ladder rows and the one-off `tools/liveranked.js` were written but have not run on the real project.
- **Not cached.** Every open reads the database once (a single indexed statement). Fine at this size; a short cache is a one-line decision if it ever matters.
- **The numbers are placeholders the user may rule on:** three games to be listed, the top fifty, the last ten.
- **Names can be old.** The latest games show the names the players had when the game ended; a player who renames later keeps the old name on old rows.
- Ranks are positions: two players on the same rating still get different ranks (more games, then name decides).
- Nothing yet stops two friends farming rating by conceding on turn one, so a ladder can be gamed; a minimum-length rule is still a question for the user.
- Hero names on the list come from the page's own hero list; a hero the page does not know shows its key in capitals-first form.
