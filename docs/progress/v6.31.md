# Progress report — v6.31 (2026-11-14)

## What shipped
- **Your name is on the board.** At a server table, each player's name sits under their hero on the table board, on both phones: yours under yours, theirs under
  theirs. A player with no name looks exactly as before. It is still there after a reload or when the same player sits down on another phone. A long name is
  cut with "…" instead of pushing the board around.
- **At most 5 open tables per player.** A signed-in player can have five tables open at once (open = one you made, not finished, not closed, not idle for two
  days). A sixth is refused in plain words: "You already have 5 tables open, the most one player can have. Finish a game, or close one of the tables below, then
  open a new one." The screen lists the five table codes with a **Close** button on each. Finished games stop counting. Tables you only joined never count.
  Tables made without a name (no sign-in) are unchanged.

## Not known / not built yet (the honest list)
- **Not deployed yet.** There is one new SQL file (`005_table_cap.sql`, run it first) and a new function version. Until the function is redeployed the phones still
  play as before; do not redeploy the function before running the SQL.
- **The live check was written but has not run against the real project** (names on both boards need the new page). Everything else was run offline.
- The cap only applies to signed-in tables. A phone that cannot sign in opens a casual table, and casual tables stay uncapped (as they always were).
- A name is copied into the table when a player sits down: a name changed mid-game shows the next time that player sits down.
- Closing a table gives the other phone no notice; it finds out the next time it talks to the server (the usual "your seat is gone" line).
- Not built yet: ranked play, a "my tables" screen beyond the list shown when the cap is hit.
