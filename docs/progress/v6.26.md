# Progress report — v6.26 (2026-11-14)

## What shipped
- **The online table exists, behind a tester's door.** Two phones can now sit at a table that needs no direct link between
  them: a referee program on the web keeps the deck and the seed secret and sends each player only their own view. It is
  live on the project you set up and was played end to end from outside. It is switched off for everyone; a phone opts in by
  opening the game with `?server=1` on the end of the address (the game remembers it, `?server=0` forgets it).
- **Found and fixed while testing it:** the page had never given its rules the card database, so cards that make tokens (a
  Runechant, a Vigor, an Agility) could not make them when the page itself ran the rules, and "Verify this game" at a server
  table failed for the same reason. Now fixed. This also means tables played on the page itself (against a friend directly or
  against the AI) now make every token they should; before, some were silently missing.
- **Two bugs found only against the real service,** both fixed: the web service reorders the fields of every message, which
  broke the seal on each one; and the check that the game's result matches had the same ordering problem.
- **A daily keep-alive** so the free project does not pause after a week idle, and **a clean-up** so tables nobody has touched
  for 48 hours are forgotten.

## Not known
- A real phone browser's connection to the service, and the page loading its helper library from the public CDN: neither can be
  reached from where this was built. First thing the two-phone test will show.
- How the free plan behaves under load (limits, quotas): only four games at once were tried.
- The final scan that no hidden card number reaches the wrong seat was run offline, not against the live service.

## How it was proven
- See the CHANGELOG entry for suite, scenes, fairness, ladder, the page drives and the live numbers.

## HOW TO TEST ON TWO PHONES
1. On both phones open https://dawnblade-ai.github.io/dawnblade-ai/?server=1 (the game remembers it after that).
2. Tap *Find an opponent*. The table screen now has a *Join a server table* button and a short note that it is an early test.
3. On one phone tap *Join a server table*, then *Open a server table*. A six-letter code appears: share it.
4. On the other phone tap *Join a server table*, then *Enter a table code*, type the code, tap *Sit down*.
5. Choose heroes, throw, and play a few turns; at the end tap *Verify this game*.

Report back: did both phones sit down; did the game play to the end; did "Verify this game" say Verified; any banner text
(for example "reconnecting" or "not answering") and when; roughly how laggy a move felt (under a second, a few seconds, worse);
and what the phone and browser were.
