# Progress report — v6.07 (2026-11-07)

**Mission (user, 2026-11-07):** the ultimate FaB Silver Age precon competitive gaming environment and
judging engine — 100% fan-made, non-profit, for fun and glory, no ads, forever.

This report covers one CEO thread: **v6.02 → v6.07** (2026-11-07), **Hidden hands H2**, the first version
of hidden hands players can see (user ruling 2026-11-07: "Hidden hands is a must"). One Opus worker built it
in five increments; the CEO re-validated every one on the merged tree before it shipped.

## What shipped
- **v6.03 — the referee and the sealed throw.** A pure-JS SHA-256 (no secure context needed, so it works
  from `file://` on an iPhone). Rock-paper-scissors is sealed before it is shown: a late, bare, changed or
  replayed throw is refused. `engine/referee.js` holds the full game and hands each seat only its view.
- **v6.04 — your three rulings.** The soul is public; an owner may look at their own face-down intimidated
  card; the order of pitched cards on the deck bottom stays unknown to the opponent.
- **v6.05 — the two-phone table runs through the referee.** The guest's phone never receives the host's
  hand, deck order, face-down arsenal or the seed. Both phones fix the seed together, so neither can stack
  the shuffle or predict draws. If the host drops, the guest pauses; the host saves and restores.
- **v6.06 — the screens.** An honest line: "the host's phone holds the deck… play people you trust… the
  guest can verify every shuffle." **Verify this game** after the end; **Resume** for a host whose page
  reloaded; **Rejoin** for a paused guest. The AI table's feed now shows only what your seat may know, and
  the AI's face-down arsenal is drawn face down (it showed the card before).
- **v6.07 — what both players saw stays seen.** A card revealed on top of a deck or in a hand stays face up
  to both until it is no longer known.

## How it was proven
- Loopback drills over all 15 heroes: the guest's memory holds no hidden card id or name; its view equals the
  host's view of that seat after every commit. Each drill was sabotaged and caught. The drills found real
  leaks before ship (the draw-detector's fingerprint carried both deck orders and the foe's hand; a few
  engine fields named hidden cards; the view missed Fai's starting card) — all fixed.
- Two real browser pages played full games over a stubbed network: host reload mid-game, guest pause and
  rejoin, finish, reveal, and the guest's **Verify** said "Verified", 0 page errors.
- At v6.07: suite 4,042 tests, 0 fail, 5 skipped. Scenes 107/0. Fairness: nothing found. Both page blocks
  compile. Phone-size page drive 73/73 screens, 0 FAILs (now deterministic). Self-play ladder: 630 games,
  0 policy refusals, 0 invariant violations, 0 stalls.
- Your soul ruling, measured: over 12 seeds the AI's Azalea lost 3 games to Boltyn it used to win, every
  other matchup identical game for game (−0.25 wins of 14, t ≈ −1.9). The AI now sees Boltyn's soul.

## Lessons this thread paid for
- A test that deals from an unseeded random source is a flaky test waiting to happen: the v6.07 candidate
  failed one run in two until its seed was pinned. Loop a new multi-game drill before trusting it.
- The post-push script check could not see a file name with a digit in it (`sha256.js`). Fixed in
  CLAUDE.md, CI and the surface drill.
- The account's 5-hour usage limit can stop a worker mid-increment: push each increment as soon as it is green.
