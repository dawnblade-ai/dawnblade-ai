# Progress report — v6.09 (2026-11-08)

**Mission (user, 2026-11-07):** the ultimate FaB Silver Age precon competitive gaming environment and
judging engine — 100% fan-made, non-profit, for fun and glory, no ads, forever.

This report covers one CEO thread: **v6.07 → v6.09** (2026-11-07/08). The headline is **Hidden hands H3, the
neutral referee**. Two Opus workers did the work; the CEO re-checked each increment on the merged tree before
it shipped.

## What shipped
- **v6.08 — two rules fixes.** A card that leaves the arena loses its counters (CR 3.0.9, CR 1.15.3), on both
  boards: Malefic Incantation bounced to hand now comes back with 1 verse counter, not 4. **Scout the
  Periphery** looks at the deck it targets (the opponent's, if you choose), not always your own.
- **v6.09 — Judge a table.** A third device (a store tablet, a laptop) holds the game. Both players' phones
  receive only their own view: neither can see the other's hand or deck. A secret seat key lets a dropped
  phone rejoin, and a stranger with the table code gets no seat. All three devices fix the shuffle seed
  together; both players can **Verify this game** afterwards. The screen says plainly that the judge's device
  holds the deck. Also: a reloaded host used to resume up to 29 moves behind; host and judge now save after
  every move.
- **v6.09 — the referee is ready for a server, with no account opened.** The same referee runs on a
  WebSocket (`net.wsAdapter`), in a sandbox shaped like Cloudflare Workers, and under Deno (Supabase Edge's
  runtime) with the referee drills unchanged.
- **After v6.09 — stricter page checks.** The two-phone and judge drives are now seeded (a run reproduces),
  and "both phones are blind" is a hard failure checked after every action, naming each legitimate exception.

## Lessons this thread paid for
- A printed report is not a check. The judge drive printed a blindness failure and still said PASS. Anything
  a drive measures that must hold should fail the run.
- A drive that deals from the clock can't be rerun to look at a failure. Seed it first.
- Workers hit the 5-hour usage limit. One stopped with nothing pushed. Ask for a push after every green fix,
  and check idle workers' status, since a limit stop does not send a report.
