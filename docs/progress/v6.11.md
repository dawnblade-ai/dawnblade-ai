## Lessons this thread paid for
- A worker's branch can be cut from an older main. Replay its commits onto the current main and validate
  there, not on the branch.
- Two branches can each bump WIRE_V to the same number. Whoever ships second takes the next number.
- `git cherry-pick --abort` undoes the WHOLE sequence, including the commits already applied. To resolve
  a later commit in a series, finish the first commits before you start it, or pick one commit at a time.
