# Progress report — v6.29 (2026-11-14)

## What shipped
- **Your seat is yours.** The first time a phone opens or joins a server table it signs in by itself: no email, no password, nothing to type.
  The table remembers which player owns which seat, so nobody else can take it.
- **Player names.** *Find an opponent* → *Join a server table* → *Choose a name*. 3 to 16 letters, numbers and single spaces, in any language.
  A name belongs to one player only; capitals, spaces and look-alike letters do not make a new name. The lobby shows "You vs Them" by name.
- **One player, two phones: the last one wins** (your decision). Sit down at the same table on a second phone and the first phone steps aside and says so.
- **If sign-in is ever down, the game still works** as a casual table, exactly like v6.28.
- On the Supabase project: anonymous sign-in turned on (your yes), the players and names tables created, the table function redeployed.

## Not known / not built yet (the honest list)
- The sign-in lives on one phone. Clearing the browser's data, or losing the phone, loses the player and the name until the **recovery code** ships (next).
- Two tabs of the same browser are the same player, so one browser cannot sit at both seats of one table.
- Names show in the lobby only, not yet on the board during the game.
- Not built yet: the cap of 5 open tables per player, and ranked play.
